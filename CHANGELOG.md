# Changelog

## [v4.0.0] - System Monitoring Dashboard
- Added live system statistics (CPU, RAM, Disk, Uptime, Temperature).
- Added system stats API endpoint /api/system-stats.
- Added screenshot capability.
- Implemented AI Vision placeholder UI.

## [v3.0.0] - Multi-Page System Controls
- Added multi-page UI architecture (Apps, System).
- Added system control shell scripts (Mute, Volume, Lock).

## [v2.0.0] - Custom Touchscreen Deck
- Introduced Flask web server.
- Replaced KDE Connect with a custom mobile-friendly web UI.
- Added application icons and fullscreen browser API support.

## [v1.0.0] - Basic Command Deck
- Initial proof of concept.
- Added shell scripts to launch VS Code, Brave, WhatsApp, GitHub, Files, and Terminal.
